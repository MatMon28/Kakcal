# File map: Android native project

> **Scope:** Java/XML/Gradle: manifest, widget providers, layouts, drawables, build config.
>
> **Read when:** you need to know which file implements something in this area (open only this file, not the others).
>
> **Related:** [file map index](README.md)

| File or directory | Role |
| --- | --- |
| `android/app/src/main/res/drawable/splash_blank.xml`, `res/values/styles.xml` (`AppTheme.NoActionBarLaunch`), `res/values/splash_themes.xml` (generated), `java/com/kcalsync/app/LaunchBackground.java` | Launch screen with no logo: a transparent icon on the app background colour. `LaunchBackground` (`applySplashThemeWhenIdle` runs the next-start splash switch after the first frame) stores the colour sent by `JournalDevicePlugin.setLaunchBackground`, picks the matching `Splash_<hex>` style (Android 13+) and colours the window and WebView in `MainActivity`. See [Launch intro](../launch-intro.md). |
| `android/app/src/main/res/drawable/widget_tray_{minimal,mono}[_dark].xml`, `drawable-{m,h,xh,xxh,xxxh}dpi/widget_tray_angular[_dark].9.png` | Tray (pill) variants behind the Small and Extra-small buttons that follow the buttons' shape: concentric rounded rectangles (minimal 15 dp, mono 16 dp) and a chamfered 9-patch (angular, generated by `scripts/render-widget-tray.mjs`). Chosen at runtime by `applyTrayShape` in `JournalWidgetProvider.java` through the `@+id/widget_tray` id in `widget_small*.xml` / `widget_essential*.xml`. Round styles keep `widget_tray[_dark].xml`. See [Widgets](../widgets.md). |
| `android/app/src/main/res/drawable/ic_stat_kak.xml` | Reminder notification icon: the real logo (solid tiered poop with the K as a hole) as a one-colour glyph on a transparent background (drawn by Android in its own circle on the left of the notification and in the status bar; also set in `capacitor.config.json` > `plugins.LocalNotifications`). No large icon. |
| `android/app/build.gradle`, `app/proguard-rules.pro`, `app/src/main/res/raw/keep.xml`, `app/src/main/baseline-prof.txt`, `variables.gradle` | Release start-up/size set-up: R8 (`minifyEnabled`) + `shrinkResources`, keep rules, the resource keep-list for names looked up at run time (`Splash_*`, `ic_stat_kak`), the hand-written baseline profile and the `androidx.profileinstaller` version. See [Startup performance](../startup-performance.md). |
| `android/app/src/main/java/com/kcalsync/app/` | MainActivity, JournalDevicePlugin, and four JournalWidgetProvider variants: cold/warm launches, private nutrition cache, themed widget button rendering, and native launcher updates. |
| `android/app/src/main/res/layout/widget_*.xml`, `res/xml/widget_*_info.xml`, `res/drawable/widget_*.xml`, `res/values*/widget_*.xml` | RemoteViews layouts (`widget_small`, `widget_essential`, `widget_medium` (4x2: icon-less calorie cards fill the free height, macro row and buttons 40 dp each), `widget_large`) and their `*_dark` variants (only `@RemoteView` classes; spacers are `FrameLayout`s), launcher metadata, offline icon vectors, and English/Italian labels. |
| `android/app/src/main/res/drawable/widget_glyph_*.xml` | Plate-less icon glyphs (food, movement, water, poop, weight, custom) that `renderStyledActionBitmap` tints with each style's ink colour for the non-classic widget styles. |
| `android/store/kakcalculator-play-icon-512.png` | Full-bleed 512 px icon for the Play Console listing. |
| `android/settings.gradle` | Gradle entry point. Starts with the **pre-flight guard** that fails fast, with a readable message, when `../node_modules/@capacitor/android`, `../node_modules/@capacitor/app` or the generated `capacitor-cordova-android-plugins/` module is missing (see [Setup & Build](../setup-build.md)); then the standard `:app` include and `capacitor.settings.gradle`. |
| `android/capacitor.settings.gradle`, `android/app/capacitor.build.gradle` | **Generated by `npx cap sync android`; do not edit.** They map `:capacitor-android` and `:capacitor-app` to the root `node_modules/` and declare the plugin dependencies. |
| `android/gradle/wrapper/gradle-wrapper.jar`, `gradle-wrapper.properties` | Stock Gradle 8.14.3 wrapper (JAR checksum-verified against `services.gradle.org`), so `./gradlew` / `gradlew.bat` work without a system Gradle. |
| `android/app/src/androidTest/java/com/kcalsync/app/WidgetIntegrationTest.java` | On-device provider registration and intent validation tests. |
| `android/app/src/main/AndroidManifest.xml` | `MainActivity` (singleTask), four widget receivers (`JournalWidgetProvider$Small/Essential/Large/Medium`), FileProvider, permissions INTERNET, RECEIVE_BOOT_COMPLETED, POST_NOTIFICATIONS, SCHEDULE_EXACT_ALARM, CAMERA (optional feature); `allowBackup=false`. |
| `android/app/src/main/java/com/kcalsync/app/JournalDevicePlugin.java` | The local Capacitor plugin behind `src/utils/android.ts`: launcher actions, nutrition publish, theme-style updates, JSON export. |
| `android/settings.gradle`, `android/capacitor.settings.gradle` | Pre-flight guard for `node_modules/` (see [Gradle guard](../android-gradle-guard.md)) and the generated Capacitor module mapping (three modules: android, app, local-notifications). Versions: `android/build.gradle` (AGP 8.13.0), `variables.gradle` (minSdk 24, compile/target 36), `app/build.gradle` (versionCode 3, versionName 1.1.0), wrapper Gradle 8.14.3. |
| `android/app/src/test/.../ExampleUnitTest.java`, `androidTest/.../ExampleInstrumentedTest.java` | Unmodified Capacitor template tests (package `com.getcapacitor.myapp`). |
