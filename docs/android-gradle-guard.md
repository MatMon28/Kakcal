# Android Gradle guard and troubleshooting

> **Scope:** Why `node_modules/` must exist before Gradle runs, the pre-flight guard in `android/settings.gradle`, and fixes for the usual build errors.
>
> **Read when:** a Gradle/Android Studio sync or build fails (e.g. `No matching variant of project :capacitor-android`, wrapper JAR errors).
>
> **Related:** setup-build.md, ../android/BUILD_APK.md

`android/capacitor.settings.gradle` (generated by Capacitor) wires the native modules to the **root** `node_modules/`:

| Gradle subproject | Resolved from |
| --- | --- |
| `:capacitor-android` | `../node_modules/@capacitor/android/capacitor` |
| `:capacitor-app` | `../node_modules/@capacitor/app/android` |
| `:capacitor-local-notifications` | `../node_modules/@capacitor/local-notifications/android` |
| `:capacitor-cordova-android-plugins` | `android/capacitor-cordova-android-plugins/` (generated by `cap sync`, git-ignored) |

When `node_modules/` is missing or incomplete (a fresh clone, a copied or zipped folder, an interrupted install, or a OneDrive/Dropbox folder where `node_modules/` is excluded or "online-only"), stock Gradle does **not** complain: it silently creates empty placeholder subprojects with no build variants, and the build fails much later with the cryptic `No matching variant of project :capacitor-android was found` / `No variants exist`.

To prevent that, **`android/settings.gradle` runs a pre-flight guard before any project is included.** It verifies that `../node_modules/@capacitor/android` and `../node_modules/@capacitor/app` contain their Gradle modules and that `android/capacitor-cordova-android-plugins/` has been generated. If anything is missing, Gradle (and the Android Studio sync) fails immediately with a human-readable message that tells you to run `npm install` / `npx cap sync android` (or `node scripts/prepare-android.mjs`) in the project root. A missing web bundle (`android/app/src/main/assets/public/index.html`) only prints a warning, because Gradle can still compile, but the APK would open a blank screen.

**Troubleshooting**

- *"Kakcalculator Android build cannot start: Capacitor native modules were not found"* → run `npm install` and `node scripts/prepare-android.mjs` in the project root, then re-sync Gradle in Android Studio.
- *"android/capacitor-cordova-android-plugins/ has not been generated"* → `npx cap sync android` (or `android:prepare`).
- *`No matching variant of project :capacitor-* was found`* (older checkouts without the guard) → same cause, same fix: `node scripts/prepare-android.mjs`.
- *"The Capacitor CLI requires NodeJS >=22.0.0"* → install Node.js 22 LTS or newer.
- *`Could not find or load main class org.gradle.wrapper.GradleWrapperMain`* → `android/gradle/wrapper/gradle-wrapper.jar` is missing. It is the stock Gradle 8.14.3 wrapper JAR (SHA-256 `7d3a4ac4de1c32b59bc6a4eb8ecb8e612ccd0cf1ae1e99f66902da64df296172`, published at `services.gradle.org/distributions/gradle-8.14.3-wrapper.jar.sha256`); it is also shipped inside `node_modules/@capacitor/cli/assets/android-template.tar.gz`. On macOS/Linux also `chmod +x android/gradlew`.
- `cap sync` is not run automatically by Android Studio. Re-run `node scripts/prepare-android.mjs` after editing the web app or installing/removing a Capacitor plugin. A plain `npm run build` is the **browser preview** (demo seeds, service worker) and should not be synced into the APK.
