# Open Food Facts offline catalogue

> **Scope:** 550,000-product KOFF v2 binary (Italy, EU/UK, US): contents, format, search, discontinued/duplicate filtering, rebuild steps, licence, Browse Foods.
>
> **Read when:** you touch `off-foods.bin`, `offCatalog.ts`, `useOffCatalog.ts`, `build-off-catalog.mjs` or food search ranking.
>
> **All catalogue queries run in a Web Worker** (`src/workers/offCatalogSearch.worker.ts`, client `src/utils/catalogueSearch.ts`): Add food, the planner, the Custom / Settings pickers, Browse Foods (`FoodDatabaseView`), and barcode lookup (`BarcodeLookupModal`) all share the single worker instance so only one copy is held in memory. See [search-and-animation-performance.md](search-and-animation-performance.md).
>
> **Related:** data-nutrition.md, storage-and-privacy.md, file-map/data.md

**Browse the full database:** Custom > Foods > Browse Foods opens the same offline index via the Web Worker (`browseCatalogue`). Its count includes matching catalogue and local foods without counting remembered barcodes twice. Name, brand, barcode and category searches cover the whole file, not just the current page. Pages contain at most 36 decoded food records from the combined results. Favourites and custom foods retain their own filters. If the file fails to load, the browser identifies the partial list and offers a retry. Restore `public/data/off-foods.bin` from Git if it is missing. `scripts/prepare-android.mjs` copies the file into `dist/data/` (and so into the APK) and refuses to continue if its KOFF magic number is wrong.

`public/data/off-foods.bin` (39.2 MB, 550,000 products) is the offline product catalogue. It is built from the [Open Food Facts](https://world.openfoodfacts.org) CSV export by `scripts/build-off-catalog.mjs`, run with `node scripts/build-off-catalog.mjs`.

- **Kept & balanced:** a valid 8–14 digit barcode, a Latin name, a target market (Italy, EU, UK/IE/AU/NZ, or US/CA), and a complete, self-consistent per-100 g/ml table (energy, fat, carbohydrates, protein; the energy must agree with the macros within a generous tolerance, alcohol included). **Excluded:** products flagged as `en:obsolete` / `obsolete` / discontinued in name, stale 0-scan records untouched for over 6 years, and pack-size / repeated-brand / rounded-macro duplicates. **Balanced:** 7 regional quota heaps (Italy 25%, US 27%, France 12%, DACH 11%, UK/IE/AU/NZ 10%, Iberia 8%, other EU 7%, with spillover) ranked by scans, completeness, recency, and nutrient richness (current build: 137,500 Italian-market, 244,811 EU, 148,895 US, 57,150 UK products; multi-country items count in each market).
- **Saved per product:** name, deduplicated brand (83,902 brands), barcode, kcal, carbs, **sugar**, fat, protein, fibre, salt, g or ml, category, 4-bit region mask (IT/EU/US/UK), and the **classic portion** (Open Food Facts `serving_quantity`) when known: 544,883 products have sugar and 363,017 have a classic portion. Missing values are stored as unknown, never invented.
- **Sugar** is stored in `FoodItem.sugar` and snapshotted on every logged item. **Settings > Today & pages > Track sugar intake** adds it to Today beside salt, food search and quantity screens, custom-food creation, barcode results, saved meals/recipes, day overviews, Statistics averages and the daily breakdown. Products without a sugar value show `—` in food details; daily totals sum the available values. The 410 bundled foods have no sugar value.
- **Format "KOFF" v2**, chosen for constant-time speed and low memory at 550k products: little-endian, every section 8-byte aligned, wrapped in typed arrays without copying (`Float64Array` barcodes, `Uint32Array` sorted `barcodeOrder` for O(log N) binary-search lookup, deduplicated `brandId`/`brandOff`/`brandBlob`, scaled `Uint16Array` nutrients, and a sorted ASCII word `vocabBlob`/`vocabOff` + LEB128 delta-varint `postings`/`postOff` inverted index). Names and brands are UTF-8 blobs decoded only for the rows returned.
- **Search & region boost:** word-prefix intersection over name and brand using the inverted index (plus a hybrid scan fast-path when intersecting a rare word with a very common one), typically < 1–8 ms on 550,000 products (< 0.1 ms on misses). Results are tiered by whole-phrase and leading-word hits, with a tie-breaker boost for the active app language (`it` -> Italian market, `en` -> US/UK markets). Products you pick, scan, star, or use in meals/recipes are copied into `kcalsync_used_foods` (`off-<code>`, protected from eviction when referenced) so existing users never lose saved foods across catalogue updates.
- **Rebuild:** `node scripts/build-off-catalog.mjs` streams the 1.5 GB export from `static.openfoodfacts.org` (about 1.5 GB RAM, ~2 minutes), or `node scripts/build-off-catalog.mjs <export.csv.gz> --limit 550000 --out public/data/off-foods.bin` for a local file. Afterwards bump `DATA_CACHE` in `public/offline-worker.js`, then `node scripts/prepare-android.mjs`.
