# Kakcal

> **Renamed:** the app is now called **Kakcal** everywhere the end user can see it (wordmark, intro/tour, install guide, manifest, Android launcher and widget names, page title, exported file names). Internal identifiers keep the old name on purpose so nothing breaks: the GitHub repository, `kakcalculator-*.svg` file names, `WIDGET_CHANNEL`, cache names (`kakcalculator-shell-*`), the `Kakcalculator.apk` / `Kakcalculator-Android-Studio.zip` file paths and the package id `com.kcalsync.app`. See [docs/brand.md](docs/brand.md#rename-kakcalculator--kakcal).

A local-first nutrition, activity and wellness journal built with React 19, TypeScript, Vite and Tailwind CSS v4. The browser opens a guided tour of every page, with the widgets last; Android has a bundled Capacitor app, four native home-screen widgets and optional reminder [notifications](docs/notifications.md). There is no account or application backend. The browser build is also an installable, offline-capable [PWA](docs/pwa.md) ([setup instructions](docs/pwa-setup.md)); the landing page opens an install guide for iPhone/iPad, Android (web app **and** APK, including the “unknown source / could be dangerous” warning) and desktop. Installed copies always open the journal itself, never the tour. Browser builds are in normal-use mode: they start with the visitor's own empty journal, and demo seeding has to be requested with `VITE_DEMO_DATA=true`. On Android the first thing drawn is the launch animation: the system launch screen, the window, the WebView and the web boot layer are all plain background colour in the colour of your saved theme (no logo, no cream or white flash) and the [animated intro](docs/launch-intro.md) plays straight on top: it starts before the app is even evaluated, runs about 1.35× faster than the supplied SVGs (about 0.8-0.95 s) and always plays to its last frame.

**Gestures:** page and popup swipes are tuned to be sensitive; closing a popup sucks it into the bottom-bar button that opens it (a barely perceivable 60-90 ms, cut short by your next tap, and taps right after a swipe-down close are never lost); the bottom bar hides on scroll down and returns on a small scroll up; swiping the Today calendar changes the day ([gestures](docs/gestures.md), [motion](docs/motion.md)).

## Quick start

```sh
npm ci
npm run dev -- --host 0.0.0.0   # browser preview / guided tour
npm run build                   # inlined dist/index.html + PWA files (manifest, icons, worker); host dist/ over HTTPS
node scripts/prepare-android.mjs && npx cap open android   # clean Android build, then Android Studio
```

Requires Node.js 22+ (Android: JDK 21, SDK 36, Build Tools 35.0.0). More in [docs/setup-build.md](docs/setup-build.md).

**Advanced layout (Settings > Advanced):** an opt-in switch (with a *Restore original layout* button right under it). When on, a small pencil appears at the top of Today, Statistics and Body: pressing it lets you **touch a field to select it** (highlighted border, resize knobs and a remove button appear), **hold it to move it** to any free place (blank space between fields is allowed), **resize it by pulling its sides or corners** (width snaps to the 6 columns, height is free), remove it, bring removed fields back, and on Today add your own meal types, which then also appear in every meal selection (Add food, Custom meals, Foods). See [docs/advanced-layout.md](docs/advanced-layout.md).

**Advanced round (drag and drop / icons):** the advanced layout is now a real drag-and-drop editor with side and corner resize handles; *Fibre*, *Salt* and *Sugar* are three independent fields on Today and Statistics; the goal / limit badges were redesigned (solid green check circle / red warning triangle, visible on every theme); the body-part icons show the part with its joint, hand or foot (flexed arm, forearm + hand, bent leg, calf + foot, simplified neck); the profile icon in Settings > Advanced > Body measurements is centred with its text; *Delete all data* is smaller and quieter. See [docs/advanced-layout.md](docs/advanced-layout.md) and [docs/advanced-personalisation.md](docs/advanced-personalisation.md).

**Free-placement round (touch to select, long press to move):** the advanced layout has no move buttons and no dashed outlines any more. Touching a field highlights its border and shows its resize knobs and the remove button (touching blank space or another field clears it); holding a field lifts it and it can be dropped on any free cell of the 6-column grid, so blank space can sit between fields (a bar shows when a new row is inserted instead). Meal fields can be shrunk down to their icon, expand arrow and + (minimum 3 columns, 2 in Compact, x 56 px), and pressing the expand arrow of a shrunk meal restores its classic size. The **Medium widget** no longer shows icons on its intake / burned cards (native layouts and gallery preview). New file `src/utils/layoutGrid.ts`; see [docs/advanced-layout.md](docs/advanced-layout.md) and [docs/widgets.md](docs/widgets.md).

**Edit round (dashed outlines, free shapes, expand returns to the chosen shape):** the pencil now *edits* the page (the words "Personalise / Personalising" became "Edit / Editing", also in Italian). While editing, every field has a **dashed (segmented) outline**; the selected field gets a **solid border that is identical on all four sides**; the remove **X sits in the top-right corner** of the field instead of its middle. Fields are placed at **any height** on the 6-column canvas (not on rows any more), so you can build shapes like a tall field with two small ones stacked beside it, a pyramid, or staggered fields; dropped fields snap magnetically to their neighbours and a field that would overlap another pushes it down. Expanding a meal shows it in its classic form, collapsing it brings back the shape you chose. Layouts saved by the previous version are converted automatically. No new files, no `package.json` change; see [docs/advanced-layout.md](docs/advanced-layout.md).

**Polish round (icons, badges, widget pill, meal items, save prompt):** the goal / limit badges now follow the style and theme (outline in the card's own ink tinted green / red, container shape per style); the neck icon has narrower shoulders, the chest icon is a V-shaped torso with two pectorals, the biceps tape sits on the muscle and the forearm icon is a fist on a widening forearm (no longer a wrist); the Small / Extra-small widget pill in *Minimal* is a crisp hairline-bordered slate tray instead of the soft cream pill; every item of an expanded meal shows its own macros, fibre, salt and sugar; dismissing *Add food* with unsaved foods asks *Save / Don't save / Keep editing* (new `SaveBeforeCloseDialog.tsx`); Today's fibre / salt / sugar fields have the name above the number, centred like the macros; the calorie-surplus pill on Intake no longer uses the red deficit colours in the non-classic styles (`--intake-badge-*`). See [docs/advanced-personalisation.md](docs/advanced-personalisation.md), [docs/widgets.md](docs/widgets.md), [docs/journal-pages.md](docs/journal-pages.md) and [docs/calculations-colors.md](docs/calculations-colors.md).
